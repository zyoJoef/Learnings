# SOHO Network

A SOHO Network (Small Office/Home Office network) is a small-scale Local Area Network (LAN) designed to connect a limited number of devices, typically supporting 1 to 10 users in a home or small business environment.

<h2>Key Characteristics</h2>
<ul>
  <li>Compact Size: Built for individuals, freelancers, or micro-enterprises with minimal infrastructure.</li>
  <li>Cost-Effective: Uses affordable, off-the-shelf hardware rather than expensive enterprise-grade equipment.</li>
  <li>Easy Management: Designed to be set up and maintained without a dedicated IT department.</li>
  <li>Mixed Connectivity: Combines wired Ethernet connections for stability (desktops, printers) with Wi-Fi for mobile devices (laptops, phones).</li>
</ul>

<h2>Common Components</h2>
<ul>
  <li>SOHO Router: Acts as the gateway between the local network and the internet, often combining routing, a firewall, and a switch.</li>
  <li>Network Switch: Expands the number of wired ports available for local devices.</li>
  <li>Wireless Access Point: Extends Wi-Fi coverage across the home or office space.</li>
  <li>End Devices: Computers, smartphones, printers, and smart TVs.</li>
</ul>
