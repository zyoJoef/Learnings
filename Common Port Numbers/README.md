# Common Port Numbers
Network ports are virtual communication endpoints used by operating systems to sort and direct network traffic to specific applications 
or services. They range from 0 to 65535 and are categorized into well-known ports (0–1023), registered ports (1024–49151), 
and dynamic/private ports (49152–65535).

<h2>Common Port Numbers</h2>
<ul>
<li>Port 20 / 21: File Transfer Protocol (FTP) — Port 20 is used for data transfer, and Port 21 is used for command control.</li>
<li>Port 22: Secure Shell (SSH) — Used for encrypted remote login and secure file transfers (SFTP).</li>
<li>Port 23: Telnet — Unencrypted text-based remote login service (largely replaced by SSH).</li>
<li>Port 25: Simple Mail Transfer Protocol (SMTP) — Used for routing and sending email.</li>
<li>Port 53: Domain Name System (DNS) — Translates domain names into IP addresses.</li>
<li>Port 67 / 68: Dynamic Host Configuration Protocol (DHCP) — Port 67 is for the server, and Port 68 is for the client.</li>
<li>Port 80: Hypertext Transfer Protocol (HTTP) — Used for standard, unencrypted web traffic.</li>
<li>Port 110: Post Office Protocol (POP3) — Used by email clients to retrieve messages from a server.</li>
<li>Port 123: Network Time Protocol (NTP) — Used for time synchronization across devices.</li>
<li>Port 143: Internet Message Access Protocol (IMAP) — Used for managing and storing email on a server.</li>
<li>Port 443: HTTP Secure (HTTPS) — Encrypted web traffic over TLS/SSL.</li>
<li>Port 445: Server Message Block (SMB) — Used for shared network files and printers in Windows.</li>
<li>Port 3389: Remote Desktop Protocol (RDP) — Used for graphical remote desktop connections.</li>
</ul>

<h2>Common Alternative & Web Development Ports</h2>
<ul>
<li>Port 8080: HTTP Alternate — The most common port for running a secondary web server, proxy, or local development environment (e.g., Apache Tomcat, Node.js).</li>
<li>Port 8443: HTTPS Alternate — Used as a non-privileged alternative for secure web traffic, often for web server admin consoles.</li>
<li>Port 8000 / 3000 / 5000: Common Web Dev Frameworks — Popular defaults for local testing (e.g., Port 3000 for React/Node, Port 5000 for Flask/Python, Port 8000 for Django).</li>
<li>Port 9000: SonarQube / PHP-FPM — Frequently used for code quality tools and FastCGI applications.</li>
</ul>
